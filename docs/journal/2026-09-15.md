- progress-reporting pattern added to the reference spec, studied from the archive suite: reef's `kernel.Progress` (Op vocabulary with `Label`/`FileVerb`, `NilProgress`/`wantsProgress` so the kernel skips metering-only work, `LogProgress` throttled to 2s with in-file detail gated at 64MiB, `progressReader` wrapping the reader to feed `BytesCompleted`) and the c8/flo `withProgress` seam (TTY check picks the reporter, worker goroutine passes immutable `Snapshot` copies to the display, post-run summary prints after the display tears down). The subtlest rule captured: throughput from bytes actually *streamed* (a reused file completes at full logical size having streamed nothing), ETA on the logical pace, indeterminate stages render `n/a` never a fabricated percent. Exemplar command: `console verify <dir>` — real hashing of a directory, manifest check if present.
